# Mic Decks — DJ Console

A browser DJ console: record from the mic, scratch on two turntables, trigger DJ sounds, build beats on a 1–8 bar step sequencer, play scale-locked instruments, and record your mix.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Branch: `main`, folder `/root`) to use it at `https://rkitel.github.io/DJ-Console/`. The live mic works when the page is served over HTTPS like this.
